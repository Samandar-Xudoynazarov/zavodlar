# Заводлар иш столи: фойдаланиш йўриқномаси

Тил: **ўзбекча, кирилл ёзуви**. Текширилган сана: **29.10.2026**.

## 1. Дастур нима учун керак?

Дастур заводдаги ишлаб чиқариш, материаллар омбори, тайёр маҳсулот, буюртмалар ва ҳисоботларни бир жойда юритиш учун хизмат қилади. Ҳар бир заводнинг маълумотлари алоҳида ҳисобланади. Бош офисга тегишли ҳуқуқ берилган ходимлар бир нечта заводни кузатиши мумкин.

**Асосий иш кетма-кетлиги:** маълумотномаларни тайёрлаш → бошланғич қолдиқни киритиш → буюртма ва режа тузиш → кунлик факт ва сарфни ёзиш → маҳсулот жўнатиш → ҳисоботни текшириш.

## 2. Кириш, тил ва заводни танлаш

1. Администратор берган дастур ҳаволасини очинг.
2. Логин ва паролингизни киритинг, **«Кириш»** тугмасини босинг.
3. Вақтинчалик парол берилган бўлса, дастур сўраганда янги парол ўрнатинг.
4. Тил тугмаларидан бирини танланг: **UZ** — ўзбек лотин, **ЎЗ** — ўзбек кирилл, **RU** — рус тили.
5. Завод танлагичи кўринса, ишлайдиган заводингизни танланг. Ҳар бир маълумот киритишдан олдин завод номини текширинг.

Заводга бириктирилган фойдаланувчи фақат ўз заводи билан ишлайди. Телефонда қўшимча бўлимлар менюдан очилади. Кўринадиган бўлим ва тугмалар фойдаланувчи ролига боғлиқ.

## 3. Ким нима қилади?

| Рол | Асосий вазифаси |
|---|---|

| Завод раҳбари | Ўз заводида тўлиқ бошқарув ва назорат. |
| ПТО муҳандиси | Каталог, нормалар, буюртмалар, режалар, кунлик ҳисобот, омбор ва материал ҳисоботи билан ишлаш. |
| Цех бошлиғи — уста | Кунлик режа, факт, сарф ва изоҳларни киритиш; тасдиқланган режани тузиш ва сақлаш. Режани ўчириш ҳуқуқи йўқ. |
| Омборчи | Материал кирими ва чиқими, инвентаризация ҳамда ўзига очилган омбор ва техника бўлимлари билан ишлаш. |
| Бухгалтер | Материал ҳисоботини тайёрлаш ва сақлаш; кўринадиган бошқа бўлимларни текшириш. |

## 4. Ишни бошлашдан олдин

Бу ишларни администратор, раҳбар ва ПТО масъул ходимлар билан келишиб бажаради:

1. **Бошқарув** бўлимида фойдаланувчиларни яратинг, уларнинг роли ва заводини текширинг.
2. **Материаллар** бўлимида материал номлари, ўлчов бирликлари, нархлар ва керакли рецептларни киритинг.
3. **Каталог** бўлимида маҳсулот маркаси, ўлчамлари ва сарф нормаларини тўлдиринг.
4. **Цех ва техника** бўлимида чиқим ёзиладиган манзилларни тайёрланг.
5. **Қолдиқ ва эҳтиёж → Бошланғич қолдиқ** орқали ҳисоб бошланадиган сана, материал ва тайёр маҳсулот қолдиқларини киритинг.

**Бошланғич қолдиқ танланган сананинг бошидаги ҳолатдир.** Омбор ҳисоби шу санадан бошланади; ундан олдинги кунлик ҳисоботлар қолдиқ ҳисобига кирмайди. Бошланғич қолдиқдаги миқдорни яна оддий кирим сифатида ёзманг.

## 5. Материалларни омборга кирим ва чиқим қилиш

### Кирим

1. **Омбор** бўлимини очинг ва кирим амалини танланг.
2. Сана, материал ва миқдорни киритинг. Ўлчов бирлигини текширинг.
3. Зарур бўлса нарх, таъминотчи, ҳужжат ва изоҳни тўлдиринг.
4. Сақланг ва қолдиқни текширинг.

### Чиқим

1. **Омбор** бўлимида чиқим амалини танланг.
2. Сана, материал, миқдор ва керакли чиқим манзилини киритинг.
3. Маълумотларни текшириб сақланг.
4. Ёзувни **Кирим-чиқим тарихи** бўлимидан текширинг.

Келажак санасига омбор ҳаракати киритилмайди. Эски сана билан чиқим ёзилганда ҳам кейинги кунларнинг қолдиғи минусга тушмаслиги текширилади. Қолдиқ етмаса, сана, бошланғич қолдиқ ва ҳақиқий киримларни текширинг.

**Бир сарфни икки марта ёзманг:** ишлаб чиқариш сарфи кунлик ҳисоботда юритилади; айнан шу сарфни омборда яна чиқим қилиш қолдиқни такроран камайтиради.

## 6. Буюртма ва ишлаб чиқариш режасини тузиш

1. **Буюртмалар** бўлимида янги буюртма очинг.
2. Буюртмачи, шартнома рақами, сана ва муддатни киритинг.
3. Маҳсулот маркалари, буюртма миқдори ва нархларни тўлдиринг, сақланг.
4. **Буюртмалар режаси** бўлимида дастур таклиф қилган режани кўринг ёки **Тасдиқланган режа**ни очинг.
5. Тасдиқланган режани қўлда тузинг ёки мос Excel файлидан юкланг. Ой, маҳсулотлар ва кунлик миқдорларни текшириб сақланг.

Дастур прогнози ва сақланган тасдиқланган режа алоҳида кўринишлардир. Иш учун қайси режа асос бўлишини масъул ходим билан келишиб олинг.

**«Олдин жўнатилган»** майдонига фақат тизимдан фойдаланиш бошланишидан аввал жўнатилган сон ёзилади. У буюртманинг қолган миқдорини камайтиради, лекин омбор қолдиғини ўзгартирмайди. Дастурда жўнатилган маҳсулотни бу майдонга қайта ёзманг.

## 7. Кунлик ҳисоботни тўлдириш

1. **Кунлик ҳисобот**ни очинг, завод ва санани текширинг.
2. Маҳсулотлар бўйича **режа**ни киритинг. Керак бўлса **«Тасдиқланган режадан тўлдириш»** имкониятидан фойдаланинг.
3. **Факт**га амалда ишлаб чиқарилган миқдорни ёзинг. Режа — топшириқ, факт — ҳақиқий натижа.
4. Материаллар бўйича ҳақиқий **сарф**ни киритинг. **Норма (факт)** маҳсулот фактига ва каталогдаги нормаларга кўра ҳисобланади.
5. Зарур изоҳларни ёзинг, жўнатиш ва тайёр маҳсулот қолдиғини текширинг.
6. **«Сақлаш»**ни босинг ва муваффақиятли сақланганини текширинг.

Сарф нормадан 10 фоиздан кўп фарқ қилса, катак сариқ билан белгиланади. Бу фарқни текшириш кераклигини билдиради. Норма ёки факт нотўғри бўлса, сарфни сунъий мослаштириш ўрнига манба маълумотини тузатинг.

Кун юкланмаса, **«Қайта юклаш»**дан фойдаланинг. Бошқа ходим шу ҳисоботни ўзгартирган бўлса, янги ҳолатни юклаб, киритмоқчи бўлган ўзгаришингизни у билан солиштиринг.

## 8. Маҳсулот жўнатиш ва накладной

1. **Кунлик ҳисобот → Жўнатиш** қисмидан **«Накладная (PDF)»**ни очинг.
2. Ҳужжат рақами ва санаси, жўнатувчи, олувчи, машина ва ҳайдовчи маълумотларини текширинг.
3. Маҳсулотлар, миқдорлар ва нархларни тўлдиринг. Шартнома танласангиз, унда тегишли маҳсулот борлигини текширинг.
4. PDF тайёрланганда жўнатишни ёзиш ёки янгилаш белгисини текширинг: **ёқилган бўлса, PDF тайёрлаш жўнатиш маълумотларини ҳам сақлайди**.
5. PDFни юклаб олинг ёки улашинг. Кейин кунлик жўнатиш ва буюртманинг қолган миқдорини текширинг.

Мавжуд жўнатишдан очилган ҳужжат тегишли қаторларни янгилайди. Улашиш бекор қилинса, шу амал орқали жўнатиш ёзилмайди. Бир жўнатишни ҳужжат орқали ва қўлда алоҳида қайта киритманг.

## 9. Тайёр маҳсулот ва инвентаризация

**Тайёр маҳсулот** бўлимида омбордаги миқдор, буюртмаларга банд маҳсулот ва брак ҳисобини кузатинг. Марка хато киритилган бўлса, ваколатли ходим **марка тузатиш** амалидан фойдаланади: нотўғри марка камаяди, тўғри марка ортади, умумий дона сони ўзгармайди.

Материаллар омборини санаш учун:

1. **Инвентаризация → Янги инвентаризация**ни очинг.
2. Сана ва материалларни текшириб, амалда саналган миқдорларни киритинг.
3. Сақланг, дастур қолдиғи билан фарқларни текширинг.
4. Масъул ходим текширгач, **«Тасдиқлаш ва қолдиқни тўғрилаш»**ни босинг ва тасдиқланг.

Санаш натижасини сақлаш ва қолдиқни тўғрилаш алоҳида амаллардир. Тасдиқлаш омбордаги ҳисоб қолдиғини ўзгартиради.

## 10. Ҳисобот, таннарх ва бошқа бўлимлар

| Бўлим | Қандай фойдаланилади? |
|---|---|
| Ойлик ҳисобот | Ойни танлаб, режа бажарилиши, ишлаб чиқариш ва материал сарфини текширинг; мавжуд экспорт тугмаси билан файл олинг. |
| Материал ҳисоботи | Ойни танланг, кунлик ҳисоботлардан келган маълумотларни текширинг, керакли тузатиш ва имзоларни киритинг, сақланг; Word (DOCX) шаклини олинг. |
| Калькуляция | Маҳсулот таннархи ва сотув нархини кўринг. Тижорат таклифини Word шаклида тайёрлаш мумкин. Ҳисобнинг тўғрилиги материал нархлари ва маҳсулот нормаларига боғлиқ. |
| Қолдиқ ва эҳтиёж | Материал ва тайёр маҳсулот қиймати ҳамда буюртмалар учун материал эҳтиёжини текширинг. |
| Таъминотчилар | Материаллар кимдан олингани ва кирим нархлари ўзгаришини кўринг. |
| Техника ҳисоби | Ёқилғи сарфи, норма, таъмир ва техник хизмат маълумотларини юритинг. |
| Графиклар | Ойлик кўрсаткичлар ўзгаришини кузатинг. |
| Умумий панель | Бош офис ваколати бўлса ва бир нечта завод мавжуд бўлса, заводлар натижаларини бир экранда солиштиринг. |

Экспорт қилишдан олдин завод, сана ёки ой ва фильтрларни текширинг. Форматлар бўлимга қараб фарқ қилади: ҳамма бўлимда барча формат мавжуд эмас.

## 11. Хабарномалар ва Telegram

Кунлик режа биринчи марта қўйилганда, ўзгартирилганда ёки тозаланганда фаол **кузатувчи** фойдаланувчиларга хабар яратилади. Фақат факт, сарф ёки изоҳ ўзгарса, режа ҳақида такрорий хабар яратилмайди.

1. Кузатувчи ҳисоби билан киринг ва қўнғироқ белгисини очинг.
2. Администратор ботни созлаган бўлса, **«Telegramни улаш»**ни босинг.
3. Очилган шахсий бот чатида **Start**ни босинг.
4. Иловада уланиш ҳолатини текширинг.

Улаш ҳаволаси 10 дақиқа амал қилади ва бир марта ишлатилади. Уни бошқа одамга берманг. Уланишдан олдинги хабарлар Telegramга юборилмайди. Telegramга хабар келмаса, иловадаги хабарномаларни ҳам текширинг.

## 12. Файл улашиш ва телефонга ўрнатиш

Ҳисобот ёнидаги **«Улашиш»** тугмаси орқали файлни, қурилма имкониятига қараб, Telegram ёки бошқа иловага юбориш мумкин. Файл тайёр бўлгани ҳақида ойна чиқса, шу ойнадаги улашиш тугмасини босинг.

Телефонга ёрлиқ қўшиш учун дастурдаги **«Телефонга ўрнатиш»** тугмасини босинг ва кўрсатилган йўриқномани бажаринг. Бу сервердаги дастурга кириш ёрлиғи; маълумот юклаш ва сақлаш учун интернет ҳамда ишлаётган сервер керак.

## 13. Захира нусха ва фойдаланувчилар

Ваколатли администратор ёки раҳбар **Бошқарув** орқали фойдаланувчиларни бошқаради ва **Захира нусха → Юклаб олиш** орқали нусха олади. Бош офис администратори барча заводлар нусхасини, завод даражасидаги ваколатли фойдаланувчи эса ўз заводи нусхасини олади.

Муҳим ўзгаришлардан олдин ва ташкилот белгилаган даврийликда захира олинг. JSON захира файлини ҳимояланган жойда сақланг. Уни оддий ҳисобот сифатида тарқатманг. Тиклаш техник масъул томонидан бажарилади; юклаб олишнинг ўзи маълумотни тикламайди.

## 14. Муаммо чиқса

| Ҳолат | Нима қилиш керак? |
|---|---|
| Бўлим ёки таҳрирлаш тугмаси кўринмайди | Ролингизни администратор билан текширинг. |
| Нотўғри ёки бўш маълумот чиқди | Танланган завод, сана, ой ва фильтрларни текширинг. |
| Ҳисобот сақланмади | Хато хабарини ўқинг; интернетни текширинг. Бошқа ходим таҳрирлаган бўлса, янги ҳолатни юкланг. |
| Қолдиқ етарли эмас | Ҳақиқий киримлар, бошланғич қолдиқ, сана ва такрорий чиқимларни текширинг. |
| Маҳсулот ёки материал ўчмайди | У ҳисобот ёки бошқа ёзувларда ишлатилган бўлиши мумкин; масъул ходим билан тузатиш усулини танланг. |
| Парол унутилган | Администраторга мурожаат қилинг. |
| Telegram ишламаяпти | Иловадаги уланиш ҳолатини текширинг; зарур бўлса қайта уланг ёки администраторга хабар беринг. |

## 15. Кун якунида текшириш

- Тўғри завод ва сана танланган.
- Режа, факт ва ҳақиқий сарф текширилган, ҳисобот сақланган.
- Кирим, чиқим ва жўнатиш такроран ёзилмаган.
- Тайёр маҳсулот ва материал қолдиқлари текширилган.
- Жўнатиш тегишли буюртмага боғланган.
- Керакли ҳужжатлар олинган ва аниқланган фарқлар масъул ходимга билдирилган.
